# fountain-pen-dipwell-and-holder

This is a fountain pen holder. It's designed to hold a Parker fountain pen. So you can use the pen as a dip pen. If you don't want to use the cartige ot the ink converter.
The reason I made this is that it was too tiring and messy to use it as a dip pen with its original bottle.

Assembly instructions 
First, you take the epoxy and cover it where it's highlighted in the image 
<img width="902" height="867" alt="Screenshot 2026-11-05 8 18 37 PM" src="https://github.com/user-attachments/assets/101be74e-3fb3-4964-a20d-9f1463211845" />

On the outer side of the part,, there are 4 holes each. In each hole, you use an M4 heat insert. Then you take the screw through the 4 holes. This is very important: tighten it enough so that it's watertight. 
To fill this up, you use the conical hole, not the other hole in the middle, and make sure it is not plugged because it is an air escape. You can fill this up with any ink, but one important thing is that it's not recommended to put glitter ink in this for this to not be contaminated, and this is only hand washable
